# Yadisk Link Viewer

Веб-приложение для просмотра и скачивания файлов по **публичным** ссылкам Яндекс.Диска
(`https://disk.yandex.ru/d/...`, `https://disk.yandex.com/d/...`, `https://yadi.sk/d/...`)
без авторизации в Яндексе.

Сделано для случаев, когда Яндекс.Диск недоступен напрямую (прокси/антивирус на работе):
приложение запускается в GitHub Codespaces, а вы просто открываете его в браузере.

## Возможности

* Просмотр структуры папок по публичной ссылке, навигация и «хлебные крошки»
* Скачивание отдельных файлов и упаковка выбранных файлов в `.zip` (стриминг, без лишного потребления памяти)
* Фильтры по типу файлов (изображения, документы, архивы, видео, аудио, прочее)
* Сортировка по имени и размеру, пагинация (25/50/100), счётчики папок/файлов
* Предпросмотр изображений в модальном окне
* Тёмная тема (следует за настройками системы), адаптивная вёрстка

## Быстрый запуск в GitHub Codespaces (рекомендуется)

1. Откройте репозиторий на GitHub: `https://github.com/ayazmur/yadisk_viewer_project`
2. Нажмите зелёную кнопку **Code** → вкладка **Codespaces** → **New codespace**
   (или просто нажмите клавишу `.` на странице репозитория и затем **Create codespace on main**)
3. Дождитесь запуска контейнера (первый раз 2–4 минуты: он сам установит Python-зависимости).
4. Откройте терминал в Codespaces (Menu → Terminal → New Terminal, или `Ctrl+``) и выполните:

   ```bash
   python start.py
   ```

5. Скрипт сам применит миграции, соберёт статику и поднимет сервер на порту **8000**.
6. VS Code в Codespaces автоматически пробросит порт: в **панели Ports** (внизу, рядом с Terminal)
   появится ссылка вида `https://xxxx-8000.githubpreview.dev` или `https://<codespace>.<user>.app.github.dev` —
   нажмите на иконку браузера рядом с портом 8000, приложение откроется в новой вкладке.
   Если порт не появился: в панели Ports → **Forward a port** → укажите `8000`.

Готово: вставляете публичную ссылку Яндекс.Диска в поле (можно просто нажать `Ctrl+V` —
поле само попытается подхватить ссылку из буфера) и работаете с файлами.

Остановка сервера: `Ctrl+C` в терминале.

> **Важно:** Codespaces простаивает бесплатно, пока он запущен только с открытым браузером/IDE.
> Закрытые без активности codespace'ы не потребляют минуты лимита, но и сервер на `8000` тогда недоступен.

## Локальный запуск

Требуется **Python 3.10+**.

```bash
git clone https://github.com/ayazmur/yadisk_viewer_project
cd yadisk_viewer_project
python -m venv venv
.\venv\Scripts\activate        # Windows
# source venv/bin/activate     # Linux/macOS
python start.py
```

Открыть `http://127.0.0.1:8000`.

## Ручной запуск (без start.py)

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py collectstatic --noinput
uvicorn yadisk_viewer.asgi:application --host 0.0.0.0 --port 8000
```

## Использование

1. Вставьте публичную ссылку Яндекс.Диска в поле ввода и нажмите **Обзор**.
2. Переходите по папкам, используйте «↑» для перехода в родительскую папку.
3. Фильтруйте по типу и сортируйте по имени/размеру.
4. **Скачать** — загрузка одного файла.
5. Отметьте файлы чекбоксами → **Скачать выбранное (.zip)**.
6. Клик по миниатюре изображения — просмотр в полном размере (закрытие: `Esc` или клик мимо).

## FAQ

### Нужен ли форк репозитория для запуска в Codespaces?

**Нет.** Любой пользователь с бесплатным аккаунтом GitHub может открыть Codespace
прямо из публичного репозитория (кнопка **Code → Codespaces**) — права на запись в репозиторий не нужны,
вы просто запускаете код у себя в контейнере.

Форк имеет смысл, только если вы хотите вносить свои изменения в код и сохранять их.

### Кому доступен GitHub Codespaces и сколько это стоит?

* Нужен обычный аккаунт GitHub (бесплатного плана **Free** достаточно).
* Бесплатно каждому пользователю даётся **120 часов в месяц** машинки 2 ядра / 8 ГБ
  (хватает примерно на 4 часа запуска в день целый месяц) и 15 ГБ хранилища.
* По часам Codespaces «тратится» только на **активно запущенный** codespace:
  закрыли — минуты не уходят. Лимит можно увеличить платно, но для наших задач не требуется.
* Если лимит исчерпан — codespace просто не запустится до следующего месяца.
  Альтернатива в этом случае — локальный запуск (`python start.py` на своей машине).

### Что делать, если страница не открывается?

* Проверьте в панели **Ports**, что порт `8000` проброшен и статус «forwarded».
* Убедитесь, что `python start.py` запущен и не упал с ошибкой (смотрите вывод в терминале).
* Попробуйте перезапустить: `Ctrl+C`, затем снова `python start.py`.

### Безопасно ли это?

Приложение работает только с публичными ссылками Яндекс.Диска, не хранит файлы
(временные файлы ZIP удаляются сразу после отправки) и не требует никакой авторизации.
Никто, кроме вас, ссылку на ваш codespace не увидит — она доступна только вашему аккаунту GitHub.

## Технологический стек

Python 3.10+, Django 5.2, aiohttp, aiofiles, uvicorn, whitenoise, django-humanize, HTML/CSS/JS.

## Ограничения

* Работает только с **публичными** ссылками Яндекс.Диска, приватные файлы недоступны.
* Скорость ZIP-архива зависит от скорости сети контейнера и ограничений API Яндекса.
* Codespaces доступен, пока у GitHub не отозвали бесплатный тариф (матчасть может измениться).
