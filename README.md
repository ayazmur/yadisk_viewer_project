# Яндекс.Диск в браузере

Веб-приложение для работы с **Яндекс.Диском**, когда сам диск недоступен напрямую —
например, заблокирован на работе, в корпоративной сети или через прокси.

Приложение запускается на сервере (проще всего — в **GitHub Codespaces**) и проксирует
запросы к API Яндекса. Ваш браузер открывает только страницу приложения, а к Яндекс.Диску
ходит сервер — из сети GitHub, где блокировок нет.

* Публичные ссылки открываются **без авторизации**.
* Свой диск — через **OAuth Яндекса**: папки, загрузка drag & drop, просмотр фото и видео,
  скачивание и ZIP-архивы.

## Зачем это

Яндекс.Диск часто недоступен из офисных сетей. При этом ссылку на файл или папку
нужно открыть здесь и сейчас. Это приложение решает задачу так:

1. Вы запускаете его в Codespaces (облако GitHub).
2. Codespaces сам обращается к `cloud-api.yandex.net` — блокировка вашей сети его не касается.
3. Вы открываете приложение в браузере и работаете с файлами как в веб-версии Диска.

> **Важно:** для входа в свой диск браузеру всё же нужен доступ к `oauth.yandex.ru`.
> Если заблокирован только `disk.yandex.ru`, вход сработает. Если заблокирован весь Яндекс —
> останутся публичные ссылки, которые открывает сервер.

## Возможности

- Просмотр публичных ссылок Яндекс.Диска без входа в аккаунт
- Режим **«Мой диск»** через OAuth: навигация, создание папок, загрузка файлов
- **Drag & drop** нескольких файлов и панель «Загрузки» со статусом и прогрессом каждого файла
- Загрузка больших файлов **частями** — обходит лимит размера запроса прокси/Codespaces
- Просмотр **фото, видео и аудио** прямо в браузере, без скачивания; перемотка видео через `Range`
- **Список и сетка**, поиск по текущей папке, сортировка, фильтры по типу файлов
- Скачивание отдельных файлов и ZIP-архива выбранных файлов (стриминг)
- Рекурсивный ZIP всей папки
- Ручной переключатель светлой/тёмной темы, адаптивная вёрстка
- Понятные ошибки: нет прав записи, истекла сессия, файл уже существует

## Быстрый старт в GitHub Codespaces

Рекомендуемый способ: ничего не нужно устанавливать локально.

1. Откройте [репозиторий](https://github.com/ayazmur/yadisk_viewer_project).
2. Нажмите **Code → Codespaces → Create codespace on main**
   (или клавишу `.` на странице репозитория и затем **Create codespace on main**).
3. Дождитесь запуска контейнера — при первом запуске он сам поставит зависимости
   (обычно 2–4 минуты).
4. В терминале Codespaces выполните:

   ```bash
   python start.py
   ```

   Скрипт поставит зависимости, применит миграции, соберёт статику и запустит сервер
   на порту **8000**. При необходимости он спросит OAuth-ключи Яндекса
   (см. [Подключение своего диска](#подключение-своего-яндексдиска-oauth)).
5. Откройте панель **Ports** (внизу рядом с Terminal). У порта `8000`
   нажмите иконку браузера — приложение откроется по адресу вида
   `https://<имя>-8000.app.github.dev`.

Остановить сервер: `Ctrl+C` в терминале.

## Локальный запуск

Нужен [Python 3.10+](https://www.python.org/downloads/).

```bash
git clone https://github.com/ayazmur/yadisk_viewer_project
cd yadisk_viewer_project
python -m venv venv
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

python start.py
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

Ручной запуск без `start.py`:

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py collectstatic --noinput
uvicorn yadisk_viewer.asgi:application --host 0.0.0.0 --port 8000
```

## Как пользоваться

### Публичная ссылка

1. Вставьте ссылку вида `https://disk.yandex.ru/d/...` в поле на главной и нажмите **Открыть**.
2. Переходите по папкам, используйте «↑» и хлебные крошки.
3. Фильтруйте по типу, сортируйте, ищите по текущей папке.
4. Нажмите на миниатюру фото или имя видео/аудио — откроется просмотр.
5. Отметьте файлы чекбоксами → **Скачать .zip**, либо **Скачать всё .zip** для всей папки.

Публичный режим — только чтение: создавать папки и загружать файлы нельзя.

### Свой диск

1. Нажмите **Войти через Яндекс** (нужны OAuth-ключи, см. ниже).
2. В сайдбаре выберите **Мой диск**.
3. Создавайте папки кнопкой **Создать папку**.
4. Перетащите файлы в окно или нажмите **Загрузить**. Прогресс и статус —
   в панели «Загрузки» справа внизу.
5. Фото/видео открываются в модальном окне, файлы скачиваются кнопкой **Скачать**.

## Подключение своего Яндекс.Диска (OAuth)

Чтобы работать со своим диском, нужно создать OAuth-приложение Яндекса и передать
приложению `ClientID` и `Client Secret`. Это делается один раз.

### 1. Создайте приложение

1. Откройте [создание OAuth-приложения](https://oauth.yandex.ru/client/new).
2. Заполните название (например, `Yadisk Viewer`).
3. Платформа — **Веб-сервисы**.
4. В поле **Redirect URI** укажите адрес callback-страницы приложения.
5. В разделе доступов включите:
   - `cloud_api:disk.read` — чтение диска;
   - `cloud_api:disk.write` — запись (создание папок и загрузка);
   - `cloud_api:disk.info` — информация о диске;
   - `login:email`, `login:info` — чтобы приложение могло показать ваше имя и почту.

   Подробнее о правах — в [документации Yandex ID](https://yandex.ru/dev/id/doc/ru/).
6. Сохраните приложение и скопируйте **ClientID** и **Client secret**.

### 2. Какой Redirect URI указывать

Путь всегда одинаковый:

```text
/oauth/complete/yandex-oauth2/
```

Нужно указать **полный адрес**, по которому вы открываете приложение, плюс этот путь.

**В Codespaces:** откройте вкладку **Ports**, у порта `8000` скопируйте адрес
(например, `https://my-codespace-8000.app.github.dev`) и добавьте путь:

```text
https://my-codespace-8000.app.github.dev/oauth/complete/yandex-oauth2/
```

**Локально:**

```text
http://localhost:8000/oauth/complete/yandex-oauth2/
```

> Адрес должен совпадать **посимвольно**. Если пересоздать codespace и адрес изменится —
> обновите Redirect URI в настройках приложения Яндекса.

### 3. Передайте ключи приложению

**Вариант А — через `start.py`:** при запуске скрипт спросит ClientID и Client Secret.
Ключи хранятся только в памяти процесса и не записываются на диск.

**Вариант Б — переменные окружения.**

Windows PowerShell:

```powershell
$env:YANDEX_OAUTH2_KEY="ваш_client_id"
$env:YANDEX_OAUTH2_SECRET="ваш_client_secret"
python start.py
```

Linux/macOS:

```bash
export YANDEX_OAUTH2_KEY="ваш_client_id"
export YANDEX_OAUTH2_SECRET="ваш_client_secret"
python start.py
```

### 4. Войдите

Перезапустите сервер, обновите страницу и нажмите **Войти через Яндекс**.
После согласия вы попадёте в свой диск.

### Если не получается

| Проблема | Что делать |
| --- | --- |
| `redirect_uri` mismatch / ошибка Yandex | Redirect URI в приложении должен точно совпадать с адресом приложения + `/oauth/complete/yandex-oauth2/` |
| Нет права записи (noperm) | Включите `cloud_api:disk.write` в приложении и войдите заново (иногда нужно отозвать доступ и авторизоваться повторно) |
| `AuthStateForbidden` / «Wrong state parameter» | Устаревшая вкладка авторизации или старая сессия: закройте старые вкладки `oauth.yandex.ru`, обновите страницу и войдите заново |
| HTTP 413 при загрузке | Приложение уже грузит файлы частями и уменьшает часть при ошибке. Если 413 остаётся — обновите приложение и перезапустите сервер |
| «Мой диск» не появляется | Проверьте, что ключи заданы и вход выполнен; перезапустите сервер после изменения переменных |
| Сессия истекла | Войдите через Яндекс заново |

## Безопасность

Приложение рассчитано на личное использование. Что важно знать:

- **Файлы не хранятся постоянно.** Скачиваемые ZIP-архивы — временные и удаляются сразу
  после отправки. Части больших загрузок лежат во временной папке сервера
  (`/tmp/yadisk_uploads/<id>`) и удаляются после завершения или отмены; «осиротевшие»
  сессии очищаются автоматически через 6 часов.
- **OAuth-токен не попадает в браузер.** Он хранится на сервере в базе данных
  (`db.sqlite3`, исключена из git) и используется только для запросов к API Яндекса.
  JavaScript на странице не получает токен.
- **Секреты не в репозитории.** `ClientID`/`Client Secret` передаются через переменные
  окружения или ввод в `start.py`. Файл `.env` исключён из git.
- **Доступ к приложению.** По умолчанию порт Codespaces приватный: страница доступна
  только под вашим аккаунтом GitHub. Не делайте порт публичным (`Public`), если не
  понимаете последствий: любой, у кого есть ссылка, получит доступ к вашему диску
  через приложение.
- **Трафик идёт через сервер.** Файлы проходят через инфраструктуру GitHub (Codespaces),
  но не сохраняются на диске сервера, кроме временных файлов, описанных выше.
- **Публичные ссылки.** Приложение только читает данные; доступ к файлу определяется
  правами самой публичной ссылки Яндекса. Любой, у кого есть ссылка, увидит те же файлы.
- **Защита форм.** Включены CSRF-защита Django, запрет встраивания в iframe
  (`X-Frame-Options: DENY`), сессионные cookie `HttpOnly`.
- **Минимальные права.** Запрашивайте только те доступы Яндекса, которые нужны.
  Отозвать доступ можно на странице [приложений Yandex ID](https://id.yandex.ru/security/applications).
- **Для продакшена.** В `yadisk_viewer/settings.py` задайте уникальный `SECRET_KEY`,
  выключите `DEBUG`, ограничьте `ALLOWED_HOSTS` и используйте HTTPS. Текущая
  конфигурация (SQLite, локальный кэш, `DEBUG=True`) предназначена для личного
  использования, а не для многопользовательского сервиса.

> Приложение не запрашивает и не хранит ваш пароль Яндекса — только OAuth-токен,
> который вы в любой момент можете отозвать.

## Ограничения

- Для входа в свой диск браузеру нужен доступ к `oauth.yandex.ru`.
- Перемотка видео зависит от того, поддерживает ли `Range` ссылка на конкретный файл.
- Лимиты GitHub Codespaces: бесплатный план — 120 часов машинного времени и 15 ГБ
  хранилища в месяц, подробнее — в [документации Codespaces](https://docs.github.com/ru/codespaces).
- Ограничения API Яндекс.Диска (размер файлов, частота запросов) применяются как есть.
- Приложение не заменяет полноценный клиент: нет корзины, перемещения, публикации ссылок.

## FAQ

### Обязательно ли делать форк?

**Нет.** Codespaces можно запустить прямо из публичного репозитория:
**Code → Codespaces → Create codespace**. Форк нужен, только если вы хотите
сохранять свои изменения.

### Сколько стоит Codespaces?

У бесплатного аккаунта GitHub есть 120 часов в месяц (машина 2 ядра / 8 ГБ)
и 15 ГБ хранилища. Минуты расходуются, только пока codespace запущен.
Подробнее: [документация Codespaces](https://docs.github.com/ru/codespaces).

### Почему страница не открывается?

- Убедитесь, что `python start.py` работает и в терминале нет ошибок.
- В панели **Ports** порт `8000` должен быть проброшен.
- Перезапустите сервер: `Ctrl+C`, затем снова `python start.py`.

### Где хранятся OAuth-ключи и токен?

`ClientID`/`Secret` — только в переменных окружения или памяти процесса.
Токен доступа — в локальной базе `db.sqlite3` на сервере (исключена из git).
В браузер токен не передаётся.

### Почему загрузка идёт через сервер, а не напрямую в Яндекс?

Так работает обход блокировок: сервер Codespaces имеет доступ к API Яндекса.
Кроме того, браузер не может напрямую класть файлы на Яндекс из-за CORS.
Крупные файлы режутся на части, чтобы не упираться в лимит размера запроса.
