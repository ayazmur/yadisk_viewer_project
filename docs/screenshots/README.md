# Скриншоты

Положите сюда изображения с такими именами — README подхватит их автоматически:

| Файл | Что показать |
| --- | --- |
| `main.png` | Главный экран в режиме «Мой диск» |
| `uploads.png` | Панель «Загрузки» с прогрессом |
| `media.png` | Просмотр видео или фото в модальном окне |
| `public.png` | Просмотр публичной ссылки |

Рекомендуемая ширина — 1200–1600 px. Форматы: PNG, JPG, WebP (они разрешены в `.gitignore`).
